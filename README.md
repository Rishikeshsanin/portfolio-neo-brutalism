# Rishikesh Munnaluri — Neo-Brutalist Portfolio

A recruiter-focused personal portfolio built around a professional neo-brutalist visual system: bold typography, hard borders, offset shadows, expressive color blocks and intentionally tactile interactions.

## Stack

- Next.js 15
- React 19
- TypeScript
- Hand-written responsive CSS
- Vercel-ready

## Design goals

- Distinctive without sacrificing readability
- Recruiter-first information hierarchy
- Fast loading with minimal dependencies
- Responsive from mobile to large desktop
- Keyboard accessible and reduced-motion friendly
- Clear links to live demos, source code, resume and contact channels

## Featured work

- Skylark Command
- Vibify
- Imposter X
- NoCodeML
- Auralis
- EchoType
- Socio Drift

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Build

```bash
npm run build
```
